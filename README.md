# 积微 · JiWei

> **一个微信窗口装下所有琐碎。** 文章收藏、日程、待办、灵感想法、报销记账 —— 发进来就自动分好类，每天早上给你一份提要，周日压成一页周报。数据全在本机，积微成著。

## 为什么做这个

碎片化信息管理的失败，通常不是因为「没记下来」，而是三件事：

| 痛点 | 表现 | 积微的对应设计 |
|------|------|----------------|
| **只进不出** | 消息、链接、想法越攒越多，「最新到底是什么」靠脑子维护 | **压实**：每晚收口、每周压实，把 N 条原始记录变成 1 条当前状态 |
| **每次重新设计系统** | 上次的分类、模板这次不用了，坐标系一漂移，累积归零 | **规则文件化**：`RULES.md` 落盘，版本可追溯，Agent 按规则办事 |
| **系统和判断混在一起** | AI 把「觉得这方法有点旧」写成项目结论，下次看到愣住 | **证据与结论分离**：机器只管把原话贴进证据区，结论你自己写 |

## 核心能力一览

| 场景 | 你发 / 说 | 它做 |
|------|-----------|------|
| **收文章** | 转发公众号链接 | 抓正文、解析标题、去重、可选同步到 Obsidian |
| **记待办** | 「明天九点见客户」 | 带时间入库，第二天早报自动出现 |
| **存发票** | 发票 PDF +「报销」 | 识别商家金额，关联项目，随时可数、可发回微信 |
| **存想法** | 「我怀疑样本量不足」 | 单独入「想法」库，不混进待办，随时可检索 |
| **查状态** | 「我有几个待办报销」 | 直接数给你，不用翻面板 |
| **补信息** | 「补进去：这是打车费」 | 并进原条目，不重开一条 |
| **撤销** | 「取消刚才的保存」 | 撤销最近一次写入 |
| **传文件** | `/发 发票` | 把电脑上的附件直接发回微信 |

## 三层数据架构

```
S1 原始材料 (append-only)     →  capture/<日期>.jsonl      →  只在核对时看
S2 当前状态 (单一事实源)       →  projects/<项目>.md        →  每天看
S3 长期理解 (人写、机器只读)   →  notebook.md + 项目「未决」  →  想起来才看
```

**S1 可以很多，S2 必须少，S3 必须是自己写下来的话。**

## 四个自动节奏

| 时机 | 动作 | 产出 |
|------|------|------|
| **收到消息** | 当场分诊：分类、抽时间、归位 | 回执：「已执行的操作 + 保存的内容」 |
| **每天早上 08:00** | 早间提要 | 今天几件事、最早几点、带时间地点；无安排就说无 |
| **每晚 22:30** | 语义收口 | 找「做完了 / 没改善 / 决定用 X」，关任务、更项目状态 |
| **周日 21:00** | 周报压实 | 合并重复、改写四问、出一页周报（收藏只留一行摘要） |

## 关键特性深度解析

### 🔁 语义去重：同一件事不记两遍

| 情况 | 判定 |
|------|------|
| 同一天、同一段原文 | 重投，回上次回执，不再入库 |
| 24 小时内换了说法 | 去掉标点/时间词后比内容，够像认作重复 |
| 隔天再说一遍 | **算新条目** —— 每周「交周报」必须能重记 |
| 已完成 / 已丢弃 | 不拦，可重新记 |

> **只看字面相似度 + 时间窗，不调模型。** 猜错一次，你要么丢记录、要么手工清两条，比多记一条更烦。

### 🛡️ 模型挂了消息不丢

自动分类失败时，退回确定性的规则分诊再存一次，回执说明存下了什么。

- 只对**自动分诊**的消息生效
- `/发`、`/记` 等显式命令失败**不降级**
- 纯聊天模式的消息**不降级**
- 降级后**不再调用**刚才失败的模型

### 📝 公众号正文 → Obsidian 一键落盘

```yaml
# reading-inbox 配置
obsidian:
  vault: '/Users/you/Documents/Obsidian Vault'   # 库根目录
  folder: 'Weixin_Article_Analysis'              # 子目录（可省略）
```

- 文件名：`YYYY-MM-DD_标题.md`（优先用发布时间）
- Front matter：`title / source / author / publish_time / tags`
- 改标题/日期 → 写新文件 + `_sync-index.json` 自动删旧文件，**不留重复**
- 走代理（fake-IP `198.18.0.0/15`）也能抓，真内网地址仍拒绝
- 手动补同步：微信说「存到 Obsidian」或调 `reading_export_obsidian`

### 💬 微信里直接聊天，也能记账

| 模式 | 触发 | 行为 |
|------|------|------|
| **自动** | 直接发消息 | 待办/想法存库、聊天直接回、不确定追问确认 |
| **纯聊天** | `/聊天` | 暂停自动记账，需用 `/记` 显式存 |
| **退出** | `/退出` | 回自动分诊 |
| **新对话** | `/新对话` | 清空上下文和待确认提议，保留账本和模式 |

- 最近 20 轮上下文，重启不丢
- 确认保留原话与答复各自时间，跨天不算错「明天」
- 提议 24h 失效，切换模式也取消

## 四条硬规则（机器绝不越界）

1. **机器绝不改写你的本子。** 会被系统改写的本子，人就不敢认真写。
2. **项目文件只重写托管区。** `<!-- journal:managed -->` … `<!-- /journal:managed -->` 之间；找不到标记**拒绝改写**。
3. **证据必须带逐字引用。** 想写进项目进展，必须给出来源里真实存在的原话；文件变动只能记「观察」，不能据此改结论。
4. **冲突永不自动合并。** 两侧都改过就报出来让人选；自动合并会把两个都合理的改动揉成一个都不对的版本。

## 快速开始

```bash
# 1. 克隆（注意：官方仓库在 shaobrad639-cpu/jiwei）
git clone https://github.com/shaobrad639-cpu/jiwei.git
cd jiwei

# 2. 一键安装（会建数据目录、铺空账本、注册插件、生成定时任务提示词）
node install.mjs

# 3. 重启 DeepSeek Harness（必须，插件路由只在重启后挂载）

# 4. 把安装器打印的 schedules-ready.md 路径发给 agent，建四个定时任务
#    微信兜底扫描（13:00） / 早间提要（08:00） / 晚间收口（22:30） / 周报压实（周日 21:00）

# 5. 面板「碎片阅读」→ 接入微信 → 手机扫码
```

**默认账本目录：** `~/.dsh-journal/data/`（可用 `--data` 指定）  
**装完是空账本**，没有示例数据。详见 [INSTALL.md](INSTALL.md)。

## 目录结构

```
.
├── plugins/
│   ├── reading-inbox/        # 微信通道 + 阅读收件箱（17 个 agent 工具）
│   │   ├── index.js          # 装配入口：消息处理、面板接口
│   │   ├── util.js           # 纯工具：URL 归一、标题清洗、中文时间解析
│   │   ├── store.js          # 收件箱读写（串行化、临时文件替换）
│   │   ├── fetch.js          # 抓取与 Python 桥接
│   │   ├── chat.js / llm.js / wechat.js / client.js
│   │   └── tools/            # 公众号正文、元数据、发票、Obsidian 导出
│   └── journal-panel/        # 面板：今天 / 待办 / 项目 / 本子 / 想法 / 活动
├── journal/                  # 核心逻辑：journal.py + 模块 + RULES.md
├── templates/                # 数据目录空骨架
├── schedules/                # 四个定时任务的提示词模板
├── tests/                    # node --test 回归测试（82 个全过）
├── scripts/                  # check.mjs（语法/格式检查）、release.sh
├── install.mjs               # 安装器（幂等、覆盖前比对备份）
└── release-notes/            # 每版本手写说明
```

> **代码与数据分离**：`journal/` 是源码，安装器把 `.py` 复制进数据目录形成**运行副本**，数据目录自包含、可整包备份。改代码请改 `journal/` 下的源文件；安装器发现两边不一致会先备份再覆盖并提示。

## 取舍说明

| 不做的事 | 理由 |
|----------|------|
| 正文双向同步 | Markdown ↔ 结构化块往返会掉格式，第一次同步就把你写的东西改形 |
| 新增类型（只保留任务/想法/资料） | 类型多了分类失去意义——分类只回答「进哪条流水线」，找东西靠搜索 |
| 为收藏生成待办 | 「这文章挺有意思」是线索，不是任务；只有回答了问题或写下理解，才值得再走一步 |
| 给静默赋予含义 | 没勾完成≠没做、长期没提≠放弃；系统只能问「要不要暂缓」，不能替你判定 |
| 去重调模型猜语义 | 猜错成本太高，只看字面相似度+时间窗 |
